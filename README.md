# TD SDK Demo（iOS）

对接文档（网页）：https://tydeonj.github.io/td-sdk-docs/  
文档仓库：https://github.com/tydeonj/td-sdk-docs  
Android Demo：https://github.com/tydeonj/td-sdk-demo-android  

正式工程用 CocoaPods Trunk。本 Demo 从公网仓拉 `1.1.2.6`。三步速查：[接入指南.md](接入指南.md)

```bash
pod install
open TDAdsSDKDemo.xcworkspace
```

广告位只改 [`TDAdsSDKDemo/TDAdsSDKDemo/AdConfig.h`](TDAdsSDKDemo/TDAdsSDKDemo/AdConfig.h)。正式包请用你们后台自己的 App ID / 广告位 ID。
